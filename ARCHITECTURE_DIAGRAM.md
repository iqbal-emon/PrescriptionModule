## Plugin Loading Sequence

```
Application Start
       │
       ▼
┌─────────────────────────────────────┐
│  Program.cs                         │
│  - builder.Services.AddDIServices() │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│  PluginLoader.LoadPlugins()         │
│  ┌───────────────────────────────┐ │
│  │  1. Scan Plugin Directory     │ │
│  │  2. Load DLL Assemblies        │ │
│  │  3. Find IPlugin Implementations││
│  │  4. Call RegisterServices()    │ │
│  └───────────────────────────────┘ │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│  PluginLoader.LoadPlugin()          │
│  ┌───────────────────────────────┐ │
│  │  1. Load Controller Assemblies │ │
│  │  2. Register ApplicationParts  │ │
│  │  3. Enable Controller Discovery│ │
│  └───────────────────────────────┘ │
└─────────────┬───────────────────────┘
              │
              ▼
┌─────────────────────────────────────┐
│  Each Plugin's RegisterService.cs   │
│  ┌───────────────────────────────┐ │
│  │  services.AddScoped<...>      │ │
│  │  - Repositories               │ │

│  └───────────────────────────────┘ │

```
